# Portfolio

My personal developer portfolio: a single-page site with a light and a dark theme.

## Run it

It is one static file with no build step and nothing to install. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.

## Files

- `index.html`: the whole site (markup, styles and scripts).
